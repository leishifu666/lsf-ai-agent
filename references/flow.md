# Google Flow 生图渠道

入口：<https://flow.google.com/>（或用户当前提供的 Flow 项目链接）。用户点名 Flow 或给出项目链接时使用本渠道；未指定生图渠道时保留 AI Studio 默认，不因故障自动互换。Flow 的智能体与视频功能不属于本配置。

以下控件定位与选项来自原有页面适配，使用时先核对实际页面；账号、点数与下载规格可用性以当前登录态为准。

## 入口与参数

优先打开用户当前指定的 Flow 项目，不为每次生成新建空白项目。链接不可用时检查真实页面，不猜测项目 ID，不擅自打开其他历史项目。使用 Ego Lite 操作前先读 [公共操作](ego.md)，同一任务复用一个 TaskSpace。

| 参数 | 界面控件与选项 | 执行规则 |
|---|---|---|
| 模式 | 图片 / 视频 | 选择 **图片** |
| 模型系列 | Nano Banana Pro / Nano Banana 2 Lite / **Nano Banana 2.1** | **每次生成前打开选择器并选择 Nano Banana 2.1，再回读**；不沿用未核对的默认状态 |
| 宽高比 | **16:9、4:3、1:1、3:4、9:16** | 按用途主动选择，不依赖上次比例；用户已指定且可用时直接选用 |
| 输出数量 | 界面 x1 / x2 / x3 / x4 | 仅使用 **x2 / x3 / x4**，默认 **x2**；用户指定 3 或 4 张时按指定值，不生成 1 张 |
| 生成分辨率、思考等级 | 当前生成面板未提供 | 不配置或声称配置 2K/4K/High；它们不是生成阶段参数 |
| 点数提示 | 按页面实际提示核对 | 不承诺永久免费；不付费升级、不修改计费设置 |

Flow 以可见模型名 **Nano Banana 2.1** 核对，不使用 AI Studio 的模型目录 ID 选择器。`browser_policy.mjs` 中的 `IMAGE_MODEL` 仅作跨渠道路由统一标识，不代表 Flow 后端暴露相同目录 ID。

比例按画面用途主动选择：横向场景、横幅或视频配图用 `16:9`；较紧凑横图用 `4:3`；方形展示用 `1:1`；竖版产品、人物或图文用 `3:4`；全屏竖版用 `9:16`。用户未指定比例时自行选用并在回复中简短说明。用户硬性指定 Flow 未提供的比例时说明限制，不把该比例写进提示词冒充已选，也不擅自裁切或切换渠道。

## Ego Lite 配置与输入

先读取页面快照，以下选择器按当前页变化情况核对后再用：

- 设置面板入口：`button[aria-label="设置触发器"]`（区分顶部全局“设置”）。
- 模型菜单入口：`button[aria-label="选择模型系列"]`；菜单项可用 `[role="menuitem"]:has-text("Nano Banana 2.1")`，选完等待按钮标签回读。
- 图片模式：`flow-toggles[aria-label="模式"] button[role="radio"]:has-text("图片")`。
- 宽高比：例如 `flow-toggles[aria-label="宽高比"] button[role="radio"]:has-text("3:4")`。
- 数量：`loc=role:radio[name="x2"]`、`x3`、`x4`；不用运行时动态生成的 `mat-button-toggle-*` ID。
- 配置回读：检查各 `flow-toggles` 下的 `[aria-checked="true"]`，同时核对模型按钮显示文本。若菜单异步关闭或按 `Escape` 收起面板，重新打开后再核对。
- 提示框：`div.ProseMirror[contenteditable="true"]`（`role="textbox"`），区分页面中可能存在的隐藏验证码 `textarea`，不读取或操作无关节点。
- 提交：`button[aria-label="开始生成"]`。

配置前可运行本地规则校验（张数传数字）：

```javascript
const {taskRoute, IMAGE_MODEL, validateFlowImageSettings} = await import('./scripts/browser_policy.mjs');
const route = taskRoute('image', {provider: 'flow'});
const settings = validateFlowImageSettings({
  model: IMAGE_MODEL, aspectRatio: '3:4', count: 2,
});
// settings 仅作本地配置校验；下载高清重塑规格另行从 UI 选择，不传入 resolution 或 thinking。
```

输入前先读并保留用户已有草稿。仅当提示框为空或草稿明确属于本轮时，使用原生输入并比较 `innerText` 全文。记录提交前已有媒体的 `data-media-id`、本轮提示、型号/比例/张数及提交时间，核对参考素材无误后单次提交，不因生成按钮仍可见而重复发送。

## 完成与本轮身份

Flow 会按张显示独立生成卡和百分比进度。**“开始生成”按钮可见或恢复，不代表当前批次已经生成完毕。**

等待本轮所有卡片完成，排除仍在加载、百分比未满、失败卡以及历史媒体。以新的 `data-media-id` 与本轮提示关联核对；本轮完整结果数量应与请求的 2 / 3 / 4 张一致。只完成部分时如实汇报实际成功张数，不自动补发整批。

图片图块为 `img[data-media-id]`，可读取 `complete`、`naturalWidth`、`naturalHeight`、`currentSrc`。页面存在账号头像或虚拟化滚动列表时，不能简单用 `document.images.length` 或当前视口图块数判断结果；关联不明确时打开图片详情核对。

生成完成后再次打开设置面板回读型号、比例与数量。可见标签仅能证明前端配置，不能独立证明后端模型版本身份。

## 下载、像素与高清重塑

1. 悬停本轮目标图片，在该图块作用域内点击“更多选项”（例如按 `data-media-id` 限定 `xpath=//img[@data-media-id="本轮ID"]/..//button[@aria-label="更多选项"]`），避免误点顶部同名菜单。
2. 悬停“下载”展开规格选项，读取各选项状态和原生 `disabled` 属性（不可只看 `aria-disabled`）。
3. 常见规格为 **1K 原始尺寸**、**2K 已高清重塑**、**4K 已高清重塑**：
   - 默认尝试 **2K** 下载并核验真实像素。
   - **4K** 仅在任务需要且当前账号可用时选择；若禁用或提示升级，不付费升级。
   - 用户明确要求 4K 而账号未开放时如实说明阻塞，不拿 2K 冒充 4K；需要原生高分辨率（非高清重塑）而当前渠道不满足时说明限制，不自动换渠道。
4. 点击下载规格前先绑定下载监听，并在同一轮保存至本地绝对路径。高清重塑可能需要一定等待时间，观察到处理中或生成按钮可用时勿重复点击制造多次请求。
5. 下载文件按实际 MIME 与扩展名保存（常见为 `.jpg`），保存后核验文件签名、真实宽高像素、画面内容与本轮对应关系。图块预览的 `currentSrc` 尺寸可能低于下载文件，不得把预览图当作高清下载件，也不得猜测 CDN 接口或修改 URL 参数。

## 异常活动提示的恢复

若 Flow 出现“我们发现了一些异常活动”提示，先尝试原页正常刷新一次，不立即更换渠道或修改模型：

1. 保留本轮项目地址、提示全文、参考素材、型号/比例/张数、提交状态和已出现的媒体 ID，区分失败卡、生成中与已完成结果。
2. 在同一 TaskSpace、同一项目页执行一次正常刷新（`await page.reload()`），等待提示框与设置入口恢复后重新获取页面快照（刷新后旧定位句柄作废）。禁止清除 Cookie、更改浏览器环境或连续反复刷新。
3. 若页面恢复正常、无登录/验证码/人工验证阻塞，且确认上一批全部失败无有效产物：重新选择并回读 `Nano Banana 2.1`、比例与张数，恢复提示全文与参考素材后最多重提一次。若已有部分成品或仍有卡片在生成，优先等待或回收，不整批重发。
4. 若刷新后仍出现异常活动提示、重提仍失败或弹出人工验证：保留当前证据并交由用户处理，立即停止自动操作。

如实记录刷新、重提与实际产物状态，不把界面恢复误报为图片已生成。
