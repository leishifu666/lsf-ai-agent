# Hark / Claude Opus 5.5

用户指定 Claude、Opus 或 Hark 做前端审美、视觉方向或设计审查时，从 <https://hark.com/projects/new> 开始新项目，使用 Hark 当前账号配置的默认 Claude Opus 5.5。账号未配置该模型时先核对可用项。

- 明确页面任务、受众、设备、品牌和已有设计系统，按需附上相关截图或源文件。
- 同一任务补充材料和修订时继续使用本轮项目。先核对提示与草稿状态，提交一次并等到完整回答。
- 新项目无法提交时，可使用已获授权的 [普通聊天入口](https://hark.com/chat) 继续。切换前确认本轮未提交。
- 回收可在页面落实的建议，按原项目的实际界面、交互和各尺寸核验。
