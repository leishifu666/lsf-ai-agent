# Hark / Claude Opus 5.5

代码视频、强动效与动态视觉默认使用 Hark。用户点名 Claude、Opus 或 Hark 做前端审美、复杂编程、文案或评审时，也走这个入口。直接使用当前账号配置的默认 Claude Opus 5.5。账号未配置该模型时先核对可用项。

## 新项目与普通聊天

- 每个独立任务从 [新建项目](https://hark.com/projects/new) 开始。补充材料、改稿和回收结果沿用本轮项目。用户明确要续接时，打开指定项目。
- 提交前核对项目地址、输入框和提示全文。保留用户已有草稿，记录实际项目链接或本轮回答身份。
- 项目无法提交时，先确认提示未发送，再转到 [普通聊天](https://hark.com/chat)。用户指定用普通聊天时直接走该入口。已经提交或状态未明时，先回原处核对。

## 交接和验收

- 代码视频与动效交接写明主题、关键镜头、时长、画幅、素材和交付格式。按项目需要约定源码、预览、成片或渲染方式。
- 前端审美与实现给出受众、设备、已有设计系统和相关截图。复杂编程注明涉及的接口、源码与约束。文案和评审注明受众、事实、语气与用途。
- 回收完成的回答或可用产物。代码在原项目运行验证。视频成片检查文件格式、时长、画幅和关键镜头，收到源码或预览时按实际产物记录。

登录、验证码与额度等问题按 [恢复规则](recovery.md) 处理。仅修改技能时做本地检查。
