# Kimi

入口：<https://www.kimi.com/>。本技能预设 K3 / 极致；使用时读取真实菜单，不把旧型号、泛称或模型自述当作配置证明。

1. 展开 `[data-testid="model-select-trigger"]`，读取可见 `[role="menuitemradio"]` 并选择 K3。选择后若导航，等待完成再获取新快照。
2. 在模型菜单内查找“思考强度”，读取当前选项并选择“极致”。其他型号的档位不套用 K3 配置。
3. 在同轮完成菜单展开、选择和触发器回读，确认 K3 与极致。
4. 工具入口按“上传文件 / 查看更多工具”的可访问名称定位，不假定一定是带 aria-label 的 HTML button。

联网任务先检查当前是否提供开关或工具；没有独立联网开关时不编造按钮，在提示中明确检索要求，再检查实际工具调用与来源。菜单或功能说明写有搜索能力不等于本轮已检索。

遇到排队、额度或会员提示时记录真实状态，不自动升级、不反复发送、不切到旧型号。配置成功与取得有效回答分别记录。当前产品没有独立自动化模块；依据实际输入、回答范围与完成标志操作。
