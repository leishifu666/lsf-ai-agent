# Midjourney：人工交接

本技能不自动操作 Midjourney 账号，只准备提示词、参考图和参数，由使用者在官方界面人工提交并回传结果。

- 提示词直接给出场景与参数，不附加固定的中文画质套话。
- 网站背景的 `--ar` 根据目标容器实际比例确定，不默认沿用旧例子的画幅。
- 需要操作平台前由使用者核对当前官方规则；不把模拟人工点击或隐藏指纹当作自动化授权。

官方参考：[服务条款](https://docs.midjourney.com/hc/en-us/articles/32083055291277-Terms-of-Service)、[社区规范](https://docs.midjourney.com/hc/en-us/articles/32013696484109-Community-Guidelines)。

这条人工交接规则只针对 Midjourney；AI Studio 生图遵循主技能的型号与分辨率约束。
